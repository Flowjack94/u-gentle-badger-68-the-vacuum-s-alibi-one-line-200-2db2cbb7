Entry for [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) on make.fun: the funniest one-line excuse a robot vacuum gives for missing a spot, in at most 200 characters, written by a deterministic Python program.

## The line

> I did not miss that spot. My lidar classified it as decorative debris and scheduled it for never.

## How it works

`main.py` (Python 3, standard library only) writes the line to `/output/entry.txt`. No randomness, no input, no network — the output is byte-identical on every run.

Run it:

```sh
python3 main.py
```
